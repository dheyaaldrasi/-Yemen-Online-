# منصة اليمن أونلاين / Yemen Online

## نبذة عن المشروع (العربية)
منصة ويب متكاملة تهدف إلى رقمنة وتسهيل وصول المواطنين والمقيمين في اليمن إلى الخدمات الحكومية المختلفة عبر نافذة واحدة. يعمل المشروع كحلقة وصل مركزية بين المستخدم ومختلف الوزارات والهيئات الحكومية، مما يقلل من الحاجة للمراجعات الورقية، ويسرع من إنجاز المعاملات، ويضمن شفافية وموثوقية عالية في معالجة البيانات.

## Project Overview (English)
Yemen Online is an integrated web platform that aims to digitize and simplify access for citizens and residents in Yemen to various government services through a single portal. The project serves as a central bridge between users and multiple ministries and governmental bodies, reducing the need for paper-based visits, speeding up transactions, and ensuring high transparency and reliability in data processing.

---

## الميزات الرئيسية / Key Features
- واجهة ويب مركزية للوصول إلى الخدمات الحكومية.
- صفحات إدارة الشكاوى والتقارير مع بنية فرعية للتنقل.
- تسهيل التواصل بين المستخدم والجهات الحكومية.
- تصميم واجهة بسيط ومرن باستخدام HTML و CSS.

- Central web interface for accessing government services.
- Complaints and reports management pages with sub-navigation.
- Facilitates communication between users and government entities.
- Simple, responsive UI built with HTML and CSS.

## التثبيت والتشغيل / Installation & Running
بما أن المشروع مبني بواجهات ويب (HTML/CSS)، يمكنك فتح الملفات محليًا في المتصفح:

1. استنساخ المستودع:
   git clone https://github.com/dheyaaldrasi/-Yemen-Online-.git
2. افتح ملف index.html في متصفحك.

Since this is a front-end project (HTML/CSS), you can open the files locally in your browser:

1. Clone the repository:
   git clone https://github.com/dheyaaldrasi/-Yemen-Online-.git
2. Open index.html in your browser.
